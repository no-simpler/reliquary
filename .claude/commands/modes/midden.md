# Midden mode

File harness friction to `midden` the moment it happens — not at the end, where
compaction has already taken the early half. `midden guide filing` = doctrine.

File when:
- the user corrects or rejects you
- a fact that should have been declared cost repeated searching
- two directives pulled opposite ways
- a directive named something that no longer resolves
- work was done, then discarded
- a permission prompt blocked an obviously safe operation

Zero notes is the expected outcome. No evidence, no note. One note, one cause.
Target the file that should have said it. Do not look for an existing note —
the same cause folds itself.

Anything before a compact boundary is lost; say so rather than reconstruct it.

Invoked as a command at session end: sweep what is still in context, then stop.
